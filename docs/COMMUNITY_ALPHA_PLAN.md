# Community Alpha plan

## Included reference path

The first community-facing path should focus on inspecting the Studio and previewing the approved Santa V5 Narrator Mode with explicitly supplied local fixtures. This is narrower than “full video editor” and matches the implemented surface.

## Required before Alpha publication

1. Choose and freeze a release commit.
2. Add a clean-fixture package or a documented fixture generator that contains no private material.
3. Add a real new-checkout acceptance test for server, preview and export boundaries.
4. Decide whether new-project persistence is in scope; otherwise remove product-like wording from that path.
5. Publish exact Python/Node/FFmpeg support and model-license instructions.
6. Review the Draft PR and run the installation on a second machine.

## Deliberately excluded

Dora and Alex artistic approval, experimental packs, arbitrary media import, a general scene editor, word/phoneme/viseme alignment and one-click new MP4 export are excluded from the Alpha claim.
