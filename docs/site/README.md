# Fabuloom public landing page

This is a framework-free, static landing page prepared for future GitHub Pages publication. It uses no external fonts, libraries, trackers, cookies, backend, or required network services.

Preview locally from the repository root with any static server, for example:

```powershell
python -m http.server 8080 --directory docs/site
```

Then open `http://127.0.0.1:8080/`. GitHub Pages activation is intentionally not performed by this mission.

The hero graphic is decorative CSS, not a product screenshot. Real Studio screenshots are not included until a neutral, sanitized capture without proprietary character defaults is approved.
