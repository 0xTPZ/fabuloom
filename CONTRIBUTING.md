# Contributing

Fabuloom Studio is in the foundation phase. Contributions should preserve the separation between public project code and private project context.

## Before contributing

- Read `README.md`, `docs/ARCHITECTURE.md`, and `docs/GETTING_STARTED.md`.
- Do not copy code, models, voices, media, credentials, or private documentation from TopazioReader, Card Game Studio, or other projects without a compatible license and explicit authorization.
- Do not commit virtual environments, model weights, generated media, books, personal audio, caches, or temporary files.
- Keep changes focused and document architectural decisions.

## Changes

Use small, reviewable commits. Add tests when implementation begins. Update the relevant documentation without claiming functionality that has not been verified.
