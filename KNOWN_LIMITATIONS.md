# Known limitations — Alpha 0.1.0 source-only

- This branch is a Draft preparation, not a published release.
- Kokoro, model weights, voices, FFmpeg and virtual environments are not bundled.
- Real narration requires an optional local Kokoro installation and a user-approved model download.
- Native Windows file-picker validation remains pending human confirmation.
- Canvas × FFmpeg visual parity is documented as PARTIAL; compression, crop and timing instrumentation can produce inconclusive comparisons.
- The repository currently contains 178 identity-bearing artistic assets whose public redistribution authorization is not established by the MIT code license.
- Santa V5, Dora, Alex, logos and Topazioverse artwork must not be redistributed until owner authorization and provenance notices are recorded.
