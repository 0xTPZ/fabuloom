# User guide

## Dashboard

The dashboard summarizes the local checkout and identifies which capabilities are present. “Local”, “browser”, “CLI” and “partial” labels are intentional status indicators, not promises of a complete production pipeline.

## Projects

The current view lists known local productions. New project persistence is not implemented in this Alpha preparation; the disabled “Novo projeto” control is expected.

## Script

The script view edits the current browser-local draft. It does not automatically create a complete scene plan or guarantee that changed text is synthesized into new audio.

## Narrators

Santa V5 is the approved production reference for this branch. Dora and Alex are visible for integration inspection but are marked as awaiting artistic approval. Older packs and experiments remain in DEV only.

## Audio and preview

When a measured local manifest and WAV are available, the browser can play the known timeline and drive RMS-based mouth states. Word, phoneme and viseme alignment is not available. A missing manifest is a data condition, not a reason to copy files from another machine.

## Export

The Exportação view links existing local outputs. It does not pretend to be a new render button. New exports are generated by the documented Python/FFmpeg examples, with their input requirements stated in the corresponding `docs/*` file.

## DEV area

DEV pages are diagnostic and experimental. Their presence does not mean that their packs, labs or visual states are Alpha-supported features.
