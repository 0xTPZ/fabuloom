# Fabuloom Studio

O Fabuloom Studio é um estúdio open source e local-first para transformar roteiros em vídeos narrados, com personagens, movimentos de câmera e exportação via FFmpeg.

> **Fabuloom Studio 0.1.0-alpha — em preparação, ainda não lançado oficialmente.**

O desenvolvimento funcional está na branch [`release/fabuloom-alpha-preparation`](https://github.com/0xTPZ/fabuloom/tree/release/fabuloom-alpha-preparation), acompanhado pela [PR #33](https://github.com/0xTPZ/fabuloom/pull/33). As funcionalidades dessa branch não são atribuídas à `main` antes da revisão e do merge.

## O que a Alpha em desenvolvimento já faz

- Criação e persistência de projetos.
- Edição de roteiros e cenas.
- Importação de imagens e movimentos de câmera.
- Prévia cinematográfica e exportação MP4 via FFmpeg.
- Narração opcional com Kokoro.
- Biblioteca de personagens e packs instalados separadamente.
- Pack neutro `community-demo-v1`, com o personagem demonstrativo Ponto.
- Testes Python, Node e Playwright do fluxo público.

O Fabuloom foi pensado para escritores, criadores de conteúdo, artistas, produtores independentes e desenvolvedores. Ele não é apresentado como substituto do Premiere, CapCut ou outro editor profissional.
